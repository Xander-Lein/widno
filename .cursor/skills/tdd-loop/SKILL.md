# TDD Loop

Работай строго по циклу:

1. Для каждого пункта плана напиши или обнови автотест.
2. Запусти минимальный релевантный набор тестов.
3. Убедись, что тесты падают по ожидаемой причине (**RED**). Не имитируй RED, если тест уже проходит.
4. Напиши минимальную реализацию.
5. Снова запусти тесты.
6. При ошибке прочитай полный лог, определи причину, исправь код или тест только при доказанной ошибке в контракте.
7. Повторяй цикл до **GREEN**.
8. Запусти полный набор проверок проекта и сопоставь результат с критериями приёмки.

В отчёте указывай команду, статус RED/GREEN и краткую причину каждого исправления. Не объявляй задачу готовой при падающих или не запускавшихся проверках.
