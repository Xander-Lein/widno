# /do-branch-to-master

Используй skill `do-branch-to-master`.

Подготовь подтверждённые изменения к продвижению из рабочей ветки в `master`, сначала выполни `/do-documentation`, затем проведи review, merge и встроенный release-checklist. `/do-documentation` также можно вызывать отдельно. Не коммить и не удаляй изменения без подтверждения пользователя.
