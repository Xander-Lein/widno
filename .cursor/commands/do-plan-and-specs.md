# /do-plan-and-specs

Используй skill `do-plan-and-specs`.

На основе подтверждённых ответов сформируй спецификацию, критерии приёмки, task graph и план. После утверждения плана подготовь отдельную ветку или Git worktree до начала реализации.

Для сложной задачи отдельно укажи, какие независимые части можно делегировать субагентам, их границы файлов, критерии проверки и способ сборки результатов координатором.
