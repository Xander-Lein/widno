# /do-tdd-loop

Используй skill `do-tdd-loop`.

Реализуй утверждённый план вертикальными срезами: сначала тест, затем RED, минимальная реализация, GREEN и повтор цикла до завершения всех критериев приёмки.

Независимые срезы можно делегировать субагентам, но координатор обязан проверить их diff и тесты самостоятельно.
